## 六、深度测试发现的缺陷修复（归入 v1.0.2.1）

对 v1.0.2.1 实际运行日志（`publish-v1.0.2.1/logs/`）的分析发现两个缺陷，
连同后续的漏洞库数据修正与扩充一并修复，全部归入 v1.0.2.1 单一版本。

### 6.1 发现过程与证据

**缺陷 1：日志无限膨胀**

| 证据 | 值 |
|---|---|
| `expert_scan_20260902.log` | 41,303,112 字节（约 41 MB / 493,875 行） |
| `expert_scan_20260903.log` | 40,538,777 字节（约 40 MB） |
| 重复行统计 | `[Rust stdout]` 类行重复 3,000+ 次 |
| 成因 | Rust 引擎以 INFO 级别逐端口打印（`scan_tcp_port: ... -> filtered`、`[result] ...`），C# 端无过滤全量写日志，且行内含 ANSI 转义序列 |

**缺陷 2：DNS 解析未观察异常**

`app_20260902.log` / `app_20260903.log` 中出现多条：
`A Task's exception(s) were not observed ... rethrown by the finalizer thread. (不知道这样的主机。)`
源自 `ResolveHostnameAsync` 超时返回后 `dnsTask` 的异常无人接管。

### 6.2 修复内容

| 缺陷 | 修复 | 文件 |
|---|---|---|
| 日志膨胀 | `ShouldSkipRustOutput()` 过滤 INFO/DEBUG/TRACE 噪音与 tracing 位置行；`AnsiEscapeRegex` 剥离 ANSI 序列；读取循环保留（防子进程缓冲区阻塞） | `RustScannerClient.cs` |
| 未观察异常 | 超时/取消路径调用 `ObserveTaskException(dnsTask)` 消化异常 | `ExpertModeWindow.xaml.cs` |

### 6.3 漏洞库数据修正与扩充（同批归入 v1.0.2.1）

**数据修正**：Cisco IOS XE / MOVEit / Citrix / Pulse 四条规则的 `AffectedService`
补上产品名，彻底消除"任何 HTTP 服务命中产品专属 CVE"的残留误报。

**规则扩充**：新增 5 条配置类风险规则（`CONFIG-TELNET-PLAINTEXT` 高危、
`CONFIG-FTP-PLAINTEXT` 中危、`CONFIG-HTTP-PLAINTEXT` 低危、`CONFIG-RDP-EXPOSED` 高危、
`CONFIG-SMB-EXPOSED` 高危）。此类风险由协议特性决定，端口 + 服务匹配即可确认。
此前目标开放 23/Telnet 却"该报未报"，扩充后可正确检出。

漏洞库总数：31 → 36 条。
