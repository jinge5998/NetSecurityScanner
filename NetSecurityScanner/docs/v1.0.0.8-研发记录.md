## 九、已知问题与注意事项

1. **警告(非致命)**: 101 个 CS4014/CS0414/CS8622 警告，均为项目历史遗留，非本次引入
2. **HasWebView 检测**: 基于 Info.plist 字符串匹配(WKWebView/UIWebView/SFSafariViewController)，不解析 Mach-O 符号表
3. **敏感 API 检测**: 基于 plist 字符串匹配，实际应解析 Mach-O `__TEXT.__objc_methname` 段获取准确结果
4. **SCA 版本检测**: 仅从 framework 的 Info.plist 提取版本，部分 SDK 可能不包含完整版本信息
5. **并行扫描**: 默认并发数 3，大文件建议降低并发
6. **存储安全检测**: 基于符号表和 Info.plist 字符串匹配，无法验证实际运行时行为
7. **动态库注入检测**: 基于符号表和 Mach-O 字符串搜索，无法检测运行时 dlopen 注入
8. **隐私合规检测**: 基于符号检测是否存在 API 使用，无法验证实际合规流程
