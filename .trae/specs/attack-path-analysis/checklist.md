# 功能特性
- 左侧路径列表支持按风险等级过滤（全部/严重/高危/中危）
- 右侧详情面板显示：路径概览、潜在影响、攻击步骤流程、防御建议
- 攻击步骤可视化包含：步骤编号、标题、描述、目标端口、依赖漏洞、风险评分
- 防御建议智能生成，根据攻击路径类型（Web/远程/数据库/文件/组合）提供针对性建议
- 支持导出JSON和文本格式报告
- 支持刷新重新加载数据
